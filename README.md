## How I work

<details>
<summary><b>Engineering principles</b></summary>

<br>

- **Boring technology, deliberately.** Postgres until Postgres is genuinely the bottleneck.
- **The schema is the product.** Most bugs I've shipped were data model decisions made in a hurry.
- **Ship small, ship often.** Long-lived branches are a process smell, not a code one.
- **Observability before scale.** You cannot optimise what you cannot see.
- **Write it down.** An ADR costs twenty minutes and saves the same argument three times.

</details>
