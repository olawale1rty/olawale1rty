> **Don't just write code. Build systems that matter.**

I think beyond implementation.

```mermaid
flowchart LR

    IT -.-> R

    classDef discover fill:#7C3AED,stroke:#C4B5FD,stroke-width:2px,color:#F5F3FF
    classDef build fill:#2563EB,stroke:#93C5FD,stroke-width:2px,color:#EFF6FF
```
